## PyTorch:

PyTorch is a Python library used to build machine learning and deep learning models.
It helps us create and train neural networks, which are used in many AI applications like:

- Image recognition
- Speech recognition
- Recommendation systems
- Chatbots

PyTorch makes it easy to work with data, perform calculations, and train models step by step.

## Machine Learning (ML):

Machine Learning means teaching computers to learn from data instead of programming them with fixed rules.
It is about turning data into numbers and finding patterns in those numbers so the computer can make decisions or predictions.

### Examples:

- Predicting house prices
- Detecting spam emails

## Deep Learning (DL):

Deep Learning is a part of Machine Learning that uses neural networks with many layers.
It helps computers learn complex patterns by using networks that work similar to the human brain.
Deep Learning is used when data is large and complex.

### Examples:

- Images
- Videos
- Audio
- Natural language
